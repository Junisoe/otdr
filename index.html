📖 Penjelasan Parameter

Pengaturan OTDR

  • Wavelength: Frekuensi cahaya yang digunakan (1310nm untuk short/medium, 1550nm untuk long distance)
  • Pulse Width: Lebar pulsa cahaya (semakin kecil = semakin detail, semakin besar = semakin jauh)
  • Range: Maksimal jarak pengukuran
  • Resolution: Ketelitian pengukuran jarak

Fiber Type

  • SMF: Single Mode Fiber - untuk jarak jauh, atenuasi rendah
  • MMF: Multi Mode Fiber - untuk jarak pendek, atenuasi lebih tinggi

Condition

  • OT: Operational Test (normal)
  • ER: Emergency Repair
  • PR: Pre-Installation Repair

💡 Tips & Trik

  • Gunakan naming convention yang konsisten untuk Cable ID (misal: CORE-001, CROSS-A01)
  • Template memudahkan Anda untuk membuat file dengan setting standard
  • Preview data sebelum generate untuk memastikan parameter sudah benar
  • Attenuation rate standard untuk SMF ~0.35 dB/km @ 1550nm
  • Backup file SOR original sebelum edit

🔒 Data Privacy

✅ Semua processing dilakukan di browser Anda (client-side)

✅ Tidak ada data yang dikirim ke server

✅ File diproses dan di-generate secara lokal

✅ Aman untuk data sensitif atau confidential

⚠️ Troubleshooting

File tidak bisa di-upload

  • Pastikan file format SOR yang benar
  • Coba file dari Anritsu atau tools sejenis

Data points tidak sesuai

  • Preview hanya menampilkan 20 data points pertama
  • File actual berisi semua data sesuai konfigurasi

Error saat generate

  • Pastikan semua field required sudah diisi
  • Cek console browser (F12 → Console) untuk error detail
